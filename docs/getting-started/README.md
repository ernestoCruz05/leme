# Getting started

1. [Install Leme](installation.md), or [on NixOS](nixos.md).
2. [Run it nested](nested-session.md) inside your current desktop.
3. [Copy the minimal configuration](minimal-config.md).
4. [Start a real session](first-session.md).

Then pick settings from the [configuration reference](../configuration/README.md).
On Gentoo with OpenRC, see the [Gentoo guide](../guides/gentoo-openrc.md).
