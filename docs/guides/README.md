# Guides

These pages assume that Leme already starts and that you have a working basic configuration.

- [Multi-monitor](multi-monitor.md) configures connectors, placement, and movement between outputs.
- [Bars, launchers, and notifications](bars-launchers-and-notifications.md) explains layer-shell programs and optional startup commands.
- [Locking and idle](locking-and-idle.md) describes external lockers, idle policy, and output power requests.
- [Screen sharing](screen-sharing.md) separates compositor capture from portals and PipeWire.
- [XWayland](xwayland.md) explains lazy X11 support and its failure behavior.
- [Gentoo/OpenRC](gentoo-openrc.md) documents one tested distribution-specific login setup.
- [Writing `timao` scripts](writing-timao-scripts.md) shows practical queries, subscriptions, and mode control.

The [configuration reference](../configuration/README.md) documents the settings used by these guides.
