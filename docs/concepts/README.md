# Concepts

These pages explain how Leme behaves. They are useful before changing configuration, especially if terms such as tags or adaptive layouts are new to you.

- [Tags and outputs](tags-and-outputs.md) explains per-output tags, adaptive tags, and monitor focus.
- [Layouts](layouts.md) compares dwindle, master-stack, and accordion.
- [Focus and movement](focus-and-movement.md) explains directional navigation and pointer operations.
- [Floating and fullscreen](floating-and-fullscreen.md) explains how dialogs, floating views, and fullscreen views behave.
- [External desktop services](external-desktop-services.md) explains what Leme owns and what it leaves to other programs.

Exact scfg settings live in the [configuration reference](../configuration/README.md). Commands are listed in the [command reference](../reference/commands.md).
