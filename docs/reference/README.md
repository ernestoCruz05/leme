# Reference

Use these pages when you need exact names, arguments, request policy, or current limits.

- [Commands](commands.md) lists the verbs available to keybindings and their arguments.
- [`timao`](timao.md) documents the command-line client and its output.
- [Control protocol](control-protocol.md) documents the Unix socket framing, replies, queries, events, and refusals.
- [Wayland protocols](wayland-protocols.md) lists the supported protocol behavior and request policy.
- [Limitations](limitations.md) lists current gaps and hardware caveats.

For scfg settings, use the [configuration reference](../configuration/README.md). For shell recipes, use [writing `timao` scripts](../guides/writing-timao-scripts.md).
